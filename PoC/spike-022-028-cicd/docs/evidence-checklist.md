# Evidencia — GitHub Actions

| Escenario | Resultado esperado | Ejecución |
| --- | --- | --- |
| Pull Request con pruebas correctas | Workflow exitoso | Pendiente |
| Pull Request con prueba fallida intencional | Workflow falla y bloquea integración | Pendiente |
| Etiqueta `v0.1.0` | Publica imagen etiquetada y por SHA | Pendiente |
| Etiqueta inválida | Falla antes de publicar | Pendiente |
| Intento desde contexto no autorizado | No obtiene credencial OIDC/despliegue | Pendiente |
| Reejecución del mismo commit | Artefacto trazable, sin sustitución silenciosa | Pendiente |

## Conclusión

Pendiente de ejecución en el repositorio que contiene la aplicación.
